# Security

Do not open a public issue containing tenant reports, tokens, credentials, tenant/application/owner identifiers or raw service responses. Reproduce defects with synthetic data. Report security issues privately using the contact route at https://www.tiagoscarvalho.com.

The collector makes GET requests only. It requires a pre-existing delegated Graph connection and writes local report files. Treat generated reports as internal administrative information. Review package changes before executing them. The source attribution and SHA-256 manifest are not a digital code-signing certificate.

Support scope: version 1.0.0, Global cloud, delegated work/school authentication, ordinary local app registrations. This tool is a point-in-time review aid, not a complete identity security assessment.
